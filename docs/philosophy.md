# Philosophy

This kit is built around a conservative view of AI coding automation:

- automate stable repeatable workflows
- keep risky product and business decisions human-reviewed
- make project boundaries explicit
- optimize for maintainability and handoff quality
- test whether a skill helps in real tasks before adding more

The goal is not maximum autonomy.
The goal is a small local workflow layer that makes coding agents more predictable inside real projects.

This kit was shaped by real project usage:

- repeated context warm-up across long-running tasks
- risky flow changes that needed explicit boundaries before code edits
- recurring handoff and retrospective work after implementation
- the need to keep only a few default skills and validate whether they actually help
