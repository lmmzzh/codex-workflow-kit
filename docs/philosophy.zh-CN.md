# 设计理念

这套 kit 建立在一种更保守的 AI coding 自动化观上：

- 只自动化稳定、可重复的流程
- 高风险产品和业务决策保留人审
- 把项目边界显式写出来
- 优先保证可维护性和 handoff 质量
- skill 不是写出来就算结束，必须先验证在真实任务里有没有帮助

这里追求的不是最大自治度。  
真正的目标，是做一层小而稳的本地 workflow layer，让 coding agent 在真实项目里更可预测。

这套 kit 也是从真实项目协作里长出来的：

- 连续多轮任务里反复发生的上下文热启动
- 高风险链路在写代码前必须先看边界
- 做完实现后必须留得下 handoff 和 retrospective
- 默认 skill 必须控制在很少的数量里，并验证它们是否真的有收益
