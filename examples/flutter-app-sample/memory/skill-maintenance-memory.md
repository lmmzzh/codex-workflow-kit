# Skill Maintenance Memory

## Default Skills

- `current-task-capsule`
- `high-risk-preflight`
- `handoff-retrospective`

## Specialized Skills

- `i18n-baseline-rollout`
- `figma-page-family-planner`

## Rules

- Let default skills trigger naturally when the task strongly matches.
- Invoke specialized skills explicitly unless the request is clearly i18n/Figma planning.
- Add a new skill only after the same workflow repeats several times.
- Refine an existing skill description before creating an overlapping new skill.
